# Demo video: 60 seconds, screen recording only

Record with what Windows already has (no downloads): **Snipping Tool → Record** (Windows 11), or **Win + Alt + R**
(Xbox Game Bar). 1920×1080, browser zoom 100%, dark theme, close other tabs and notifications. Record each shot
separately (5–10 s each, take two of each); join them in **Clipchamp** (built into Windows 11) and add the
captions there. No voice needed: captions carry the story. Optional calm music from Clipchamp's free library.

| # | Time | Screen | Action | Caption (on screen) |
|---|---|---|---|---|
| 1 | 0–6 s | Dashboard **Overview** (top) | Let the headline animate in; slow mouse move over the orbit | **AI agents that evolve themselves. With receipts.** |
| 2 | 6–13 s | **Tour** page | Scroll slowly: the laptop opens and the real mission replays | A real mission: specialist agents build, a QA agent checks, it gets sent back once |

Tips
- Move the mouse slowly; pause one second before every scroll so the animations start cleanly.
- If a caption feels long, cut words, not seconds: viewers read about 3 words per second.
- Export 1080p MP4. For LinkedIn or X, also export a square 1:1 crop of shots 1, 4 and 8 as a 15-second teaser.
