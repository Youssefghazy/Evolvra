# Attribution

The starter personas in `plugin/agents/` are imported verbatim from
[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
(MIT License), commit `b37b5bb`, on 2026-11-02.

Evolvra evolves these files over time. Every evolved version records its
parent version and the rationale for the change, so the lineage back to the
upstream original is always traceable. Evolved personas stay valid
agency-agents files (frontmatter: `name`, `description`, `color`) so
they can be installed with the upstream scripts into any supported tool.

Ideas borrowed (no code copied):

- **GEPA** (MIT) — reflective prompt evolution over execution traces, Pareto front.
- **OpenEvolve** (Apache-2.0) — MAP-Elites archive, island populations, artifact feedback.
- **Darwin Gödel Machine** (Apache-2.0) — promote a self-modification only when it empirically wins.
